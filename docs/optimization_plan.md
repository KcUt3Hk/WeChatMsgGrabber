# 图像识别优化技术方案与实施计划

## 1. 现状分析
当前系统在处理微信聊天记录截图时，面临以下主要挑战：
*   **截图范围冗余**：全屏或大范围截图中包含大量无效背景（如两侧留白、顶部状态栏），干扰了 OCR 引擎的注意力机制，导致小目标（表情包、缩略图）漏检。
*   **暗黑模式适配**：在深色背景下，图片边缘与背景对比度低，传统的全局阈值算法容易将图片误判为背景。
*   **多尺度目标**：同一截图中可能同时存在大图（预览图）和微小图（表情、头像），单一的预处理参数难以兼顾。

## 2. 优化方案

### 2.1 智能感兴趣区域 (ROI) 检测
在 OCR 介入之前，增加一道预处理工序：**内容区域自动裁剪**。

*   **算法原理**：
    1.  **垂直投影分析**：计算图像每一行的像素变化率（方差或边缘密度）。
    2.  **水平投影分析**：计算图像每一列的非背景像素占比。
    3.  **边界锁定**：
        *   从上下两端向内扫描，剔除大面积纯色/低纹理区域，确定 `Effective Height`。
        *   从左右两端向内扫描，剔除边框留白，确定 `Effective Width`。
    4.  **安全扩充**：在检测到的 ROI 基础上向外扩充 10-20 像素，防止切断气泡边缘。

*   **预期效果**：
    *   将 OCR 的处理视野从 "1920x1080" 聚焦到 "800x600" 的核心区域。
    *   有效像素占比提升至 80% 以上。
    *   排除顶部工具栏和底部输入框的干扰。

### 2.2 自适应图像增强
针对暗黑模式和低对比度图片，实施局部增强。

*   **CLAHE (对比度受限自适应直方图均衡化)**：
    *   不使用全局直方图均衡化（容易导致背景噪点爆炸）。
    *   采用 CLAHE 算法，将图像划分为 8x8 的小块，分别进行直方图均衡，限制对比度放大倍数（Clip Limit = 2.0）。
    *   **效果**：显著提升暗部细节（深色背景下的图片轮廓）的清晰度。

### 2.3 多尺度检测策略
在 `detect_text_regions` 阶段引入多尺度机制。

*   **原图检测**：保留 2560px 级别的高分辨率检测，捕捉微小文字和表情。
*   **降采样检测**：增加一个 0.5x 或 1280px 的降采样检测流，捕捉大尺寸图片块（大图在降采样后轮廓更闭合，不易被分割）。
*   **结果融合**：对两组检测结果进行 NMS (非极大值抑制) 融合，取置信度高或面积大的区域。

### 2.4 准确率精细化优化 (Day 3 - Latest)
针对“绿色气泡误识别”与“小图标漏检”的矛盾，进行精细化参数调优。

*   **智能填充 (Padding)**：
    *   在 OCR 预处理阶段，对裁剪出的小区域（气泡）添加 10px 填充。
    *   **原理**：OCR 引擎对边缘紧贴的文字识别率较差，添加填充显著提升了边缘文字的识别置信度，从而减少因 OCR 失败导致的“误判为图片”。

*   **小图上采样 (Upsampling)**：
    *   对高度 < 80px 的裁剪区域进行 2.0x 上采样。
    *   **效果**：增强了低分辨率表情包/图标的特征，同时帮助 OCR 更好地识别小字号文本。

*   **媒体气泡判定阈值调整**：
    *   **纯色背景阈值**：从 0.4 提升至 0.85。
        *   *原因*：0.4 的阈值过于激进，导致部分简单图标（如黑白线框图标，背景占比 ~65%）被误判为“纯色背景”而被丢弃。
        *   *新策略*：0.85 的阈值仍能有效过滤纯色文本框（背景占比 > 90%）和空区域，但允许简单图标通过。
    *   **最小面积阈值**：从 225px² (15x15) 降低至 100px² (10x10)。
        *   *效果*：支持识别更微小的行内图标或状态标识。

## 3. 实施计划

### 第一阶段：ROI 智能裁剪 (Day 1) [已完成]
1.  **开发 `detect_content_roi` 函数**：实现基于投影法的边界检测。
2.  **集成到 `OCRProcessor`**：在 `process_image` 流程最前端应用 ROI 裁剪。
3.  **坐标映射机制**：确保 OCR 返回的相对坐标能准确还原为原图的绝对坐标（关键！否则点击/裁剪会错位）。

### 第二阶段：图像增强与检测优化 (Day 1-2) [已完成]
1.  **引入 CLAHE 预处理**：在 `ImagePreprocessor` 中增加 `enhance_local_contrast` 方法。
2.  **优化 `detect_text_regions`**：
    *   针对暗黑模式调整 `adaptiveThreshold` 的 `blockSize` (从 11 调至 15 或 21)。
    *   增加 `MorphologyEx.CLOSE` 操作的核大小，确保深色背景下的图片轮廓闭合。

### 第三阶段：测试与调优 (Day 2) [已完成]
1.  **构建测试集**：
    *   包含：标准白底、暗黑模式、纯文字页、纯图片页、混合排版页。
2.  **验证指标**：
    *   **IoU (交并比)**：检测框与人工标注框的重合度 > 0.85。
    *   **Recall (召回率)**：图片/表情包漏检率 < 1%。
    *   **Precision (精确率)**：文本误判为图片的比例 < 1%。

### 第四阶段：精细化准确率提升 (Day 3) [已完成]
1.  **小目标优化**：
    *   实施小图上采样 (2.0x) 与边缘填充 (10px)。
    *   验证小字号文本和紧凑布局下的 OCR 识别率提升。
2.  **阈值重校准**：
    *   调整 `is_solid_background` 阈值至 0.85，平衡“空气泡过滤”与“简单图标保留”。
    *   降低最小面积阈值至 100px²，支持微型图标。
3.  **全量回归测试**：
    *   确保所有单元测试 (test_ocr_processor, test_smart_roi, test_ui_detection) 全部通过。

## 4. 参数调整参考

| 参数项 | 原值 | 建议调整值 | 说明 |
| :--- | :--- | :--- | :--- |
| `preprocess_max_side` | 2560 | **保持 2560** | 维持高分辨率以识别小图 |
| `detect_text_regions.min_area` | 80 | **50** | 降低阈值，捕获更小的表情包 |
| `adaptiveThreshold.blockSize` | 11 | **19** | 增大邻域，减少纹理噪点对轮廓的干扰 |
| `morphology.kernel_size` | (3,3) | **(5,5)** | 增强闭运算能力，更好地连通图片块 |
| `ROI.padding` | N/A | **20px** | 裁剪时的安全边距 |
| `is_solid_background.threshold` | 0.4 | **0.85** | 避免误杀简单图标 |
| `media_bubble.min_area` | 225 | **100** | 支持 10x10 微型图标 |

## 5. 预期成果
*   **识别率**：暗黑模式下图片识别率提升 30% 以上。
*   **误检率**：通过 ROI 裁剪，边缘干扰误检率降低至 0.5% 以下。
*   **速度**：虽然增加了 ROI 计算，但由于 OCR 处理面积大幅减小，整体处理速度预计提升 10-15%。
*   **准确度**：通过精细化阈值与上采样，解决边缘 case（微小图标、紧凑文本），实现“准确率再提高一点”的目标。
