# 用户指南更新说明 (v1.1.0)

## 新增功能：智能图片识别与去重

本次更新重点优化了聊天记录中的图片识别准确率，并新增了智能去重功能。

### 1. 自动去重 (Auto Deduplication)

系统现在会自动检测聊天记录中的重复图片。
- **原理**: 使用感知哈希 (dHash) 技术，分析图片内容的相似度。
- **效果**: 即使两张截图的尺寸略有差异，或者存在微小的压缩噪点，只要内容相似度超过 95%，系统就会自动过滤掉重复的图片。
- **好处**: 您的输出文件夹将更加整洁，不再包含大量重复的截图。

### 2. 识别准确率优化 (Enhanced Recognition)

针对用户反馈的“识别少”、“图片小”以及“文本误判”问题进行了全面修复：
- **智能裁剪 (Smart ROI)**: 系统现在会自动识别聊天区域的“有效内容”，自动去除空白背景和静态边框，让识别更聚焦。
- **暗黑模式增强**: 针对深色背景的聊天截图，内置了对比度增强算法，提升文字和图片的提取效果。
- **误判防护**: 修复了将“搞好了”、“收到”等短文本消息误识别为图片的问题。

### 3. 使用建议

为了获得最佳的识别效果：
1. **框选区域**: 在使用“框选聊天区域”功能时，尽量只包含聊天消息列表，避免包含过多的输入框或顶部标题栏。
2. **分辨率**: 保持默认的屏幕分辨率，系统已针对 macOS Retina 屏幕进行了适配。

### 4. 常见问题排查

**Q: 为什么生成的图片文件名变了？**
A: 我们移除了文件名中的时间戳后缀（例如 `_20251225...`），现在直接使用消息 ID 命名。这样做是为了防止同一张图片因为时间不同而被保存为两个不同的文件。

**Q: 还有部分文本被识别为图片怎么办？**
A: 请检查该文本是否包含特殊的艺术字体或极其复杂的背景。如果是普通文本仍被误识，请将日志反馈给我们进行微调。
